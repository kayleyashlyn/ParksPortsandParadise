# Brand Kit Specs

## 🎨 Color Palette
- **Primary:** `#004b49` (Deep Teal - used for primary buttons, hero text, and main branding)
- **Secondary:** `#e28743` (Warm Amber - used for accents, highlights, and secondary elements)
- **Background:** `#ffffff` (Pure White)
- **Surface/Muted:** `#f4f6f6` (Light Gray - for card backgrounds or layout blocks)

## 🔤 Typography
- **Headings Font:** `Playfair Display` (Serif font family)
- **Body Font:** `Inter` (Sans-serif font family)

## 📐 Styling Guidelines
- **Border Radius:** `0.5rem` (Rounded corners for cards, buttons, inputs)
- **Buttons:** Solid primary color for primary actions, outlined amber for secondary actions.
