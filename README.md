# ParksPortsandParadise

A modern, high-performance web platform built to replace a drag-and-drop Squarespace site. Designed for fast page loads, bespoke itinerary showcases, dynamic destination filtering, and seamless inquiry lead capture.

## 🚀 Key Features
- **Dynamic Itinerary & Destination Showcase:** Powered by Sanity.io Headless CMS for flexible content management.
- **Interactive Trip Planner & Lead Capture:** Custom multi-step inquiry form with type-safe validation.
- **Rich Media & Interactive Maps:** High-resolution optimized image delivery and interactive trip route mapping.
- **Tailored Travel SEO:** Automated structured data (JSON-LD) for `Trip` and `TouristAttraction` entities, dynamic XML sitemaps, and optimized metadata.
- **Lightning-Fast Performance:** Built on Next.js App Router with Server-Side Rendering (SSR) and Incremental Static Regeneration (ISR).

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, TypeScript)
- **CMS:** Sanity.io
- **Styling & UI:** Tailwind CSS, shadcn/ui, Lucide Icons
- **Forms & Validation:** React Hook Form, Zod
- **Deployment:** Vercel
